# 🧠 Local AI Setup (Ollama)

This guide explains how to run **AI Learning Planner** using **local AI (Ollama)** instead of Gemini.

No API keys.  
No internet required.  
Fully local.

---

## 🧩 Why use Ollama?

- Free & offline
- Faster for local dev
- No rate limits
- No API cost
- Works without env changes

---

## 🖥️ Step 1: Install Ollama

### 🔗 Download
https://ollama.com/download

Install for your OS:
- Windows
- macOS
- Linux

---

## 🚀 Step 2: Start Ollama

Open terminal and run:

```bash
ollama run llama3
